# Hazır agent

`LabelPrintAgent.exe` — Windows üçün tək fayl, Python lazım deyil. Printerin qoşulduğu kompüterə kopyalayın,
açın, pəncərədə server ünvanı, baza, token (Odoo → Etiket çapı → Konfiqurator → Ayarlar) və printeri seçin.
`config.ini` exe-nin yanında yaranır. Yenidən yığmaq: `label_print_direct/tools/agent/build_exe.bat`.
